# 易学研习室 · Yi Learning Lab

独立维护的易学学习工作台，作为个人全方位成长系统的进阶学习入口。

本版已经实现：

- 64卦结构识别、文王卦序、上下经卦与384条爻辞；乾坤用九用六单列。
- 三钱法手动输入、逐爻记录与模拟投掷；显示本卦、之卦与动爻。
- 互卦、错卦、综卦；中位、当位、相应、阴承阳与阴乘阳。
- 常见京房八宫分类、世应位置。
- 四类互动练习、答题反馈、错题盒与按间隔安排复习。
- 学习卡片、编辑草稿、阅读标记、12单元验收、JSON备份合并、Markdown导出。
- 洛书八条线的验算、河图配对与概念索引。
- 日期区间学习摘要、成长系统内嵌消息和摘要JSON导入协议。

## 本地运行与验证

运行环境：Node 22或更新版本。无需安装第三方依赖。

```bash
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

打开 `http://localhost:8080`。直接双击源码 `index.html` 会受到浏览器ES模块的文件协议限制，应通过HTTP服务器运行。

17项测试包括所有4096种三钱结果组合、64卦结构与384个爻题、八宫划分、重复保存、备份合并、同卡片跨窗口编辑冲突、卡片转义和页面事件。界面测试采用DOM模拟。发布后已在真实桌面浏览器检查首页、既济结构、经典阅读、练习入口、成长系统内嵌及摘要发送与取消；尚未完成移动端与离线验收。

## 与成长系统的关系

`personal-growth-app`继续维护长期目标、时间安排、课程、传统文化背景和每周复盘。本项目维护专门的易学练习与阅读。成长系统已接入本项目，可从「传统文化 → 易学研习室 · 进阶」打开内嵌工作台或全屏入口。接入脚本只负责摘要校验、预览与保存。

内嵌URL：`?embed=1#home`。`?hexagram=63#reader`可打开指定卦。内嵌页在「备份与接入」发送摘要，父页校验来源窗口、站点、格式与长度，再由用户预览保存。摘要按保存日期进入成长系统周复盘；实际学习区间保留在记录内容与字段中。相同摘要去重。

协议：`postMessage({type:'yi-learning:summary',payload:<summary>}, 'https://shaun050427.github.io')`。完整笔记、成长系统数据库、GitHub令牌不在协议内。两个应用使用不同的本机数据键；这属于数据组织隔离，并非同源安全隔离。GitHub Pages的同一账号项目共享浏览器origin。

## 记录与恢复

完整学习记录保存在当前浏览器 `yi-learning-lab:v1`；草稿保存在 `yi-learning-lab:draft:v1`。尚未实现云同步。换设备或清理浏览器前导出完整JSON。备份按ID合并，同ID较新版本优先；删除卡片有删除标记。旧备份不会自动复活已删除卡片，需从备份取回内容作为新卡片保存。

草稿与已保存卡片分别管理。编辑同一张卡片时，如果其他窗口已修改它，当前保存会停止并保留草稿。浏览器localStorage不提供跨标签事务，极短时间内同时写入仍有竞争窗口；重要记录请定期导出。

## 文本与来源

古籍正文来自维基文库《周易》逐卦录入页（2026-10-11取回），每卦保留页面地址和固定修订编号。原文为公有领域；异文附记单独展示，现代译注未复制。`src/data/source-transcription.json`保留所取回的正文转录；`source-manifest.json`列出出处与修订版本。`cd scripts && python assemble-data.py`从转录重新生成数据。

原文入口：https://zh.wikisource.org/wiki/周易

八宫表：https://zh.wikisource.org/wiki/周易#分宮卦象次序表

二十四节气：https://www.hko.gov.hk/sc/gts/time/24solarterms.htm

来源版本中的个别用字与通行版本可能不同，本版保留原字并显示异文附记。尚未对全部文本进行跨版本学术校勘。学习提示为本项目编写，应与经文和个人心得区分。

## 可继续扩展的模块

数据、确定规则、题目与个人记录已经分开。下一阶段可增加可对照的注释版本、更多题型与完整纳甲规则。当前没有实现月日旺衰、六亲用神判断，亦没有奇门、太乙、六壬排盘，不应把八宫世应视作完整纳甲六爻占法。

## 维护原则

修改卦象引擎或数据先跑测试；修改网页样式应补真实浏览器检查。发布后更新独立应用缓存版本；成长系统补丁只维护桥接入口，不复制整个易学应用。
